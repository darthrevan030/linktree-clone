## Reach

Published to the Chrome Web Store on Manifest V3, Not Just Black earned
**50,000+ impressions** and peaked at **2,540 weekly active users** — entirely
through organic Web Store discovery, with no marketing spend.

## The interesting part is the pipeline

The theme itself is a manifest and a palette. The engineering is in shipping it
repeatably: a build and release pipeline built on **Makefiles and shell
scripting** for CRX packaging, with **OpenSSL signing** for Web Store
distribution.

That turned publishing from a manual, error-prone ritual into a single command —
which matters when you're managing the full product lifecycle solo, from
development through Web Store review, publishing, and version updates.
